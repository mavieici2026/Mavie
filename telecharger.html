📱 Télécharger pour Android 🌐 Ouvrir sans télécharger

Comment installer sur Android

  1. Appuie sur Télécharger pour Android.
  2. Quand le téléchargement finit, appuie sur le fichier Ma Vie.apk.
  3. Si le téléphone dit « Installation bloquée », appuie sur Paramètres et autorise l'installation depuis ce navigateur ou ce gestionnaire de fichiers.
  4. Appuie sur Installer, puis sur Ouvrir.

Pas envie de télécharger un fichier ?

  1. Appuie sur Ouvrir sans télécharger.
  2. Dans le menu de ton navigateur (les 3 points), choisis Ajouter à l'écran d'accueil ou Installer l'application.

Sur iPhone, utilise « Ouvrir sans télécharger » puis « Sur l'écran d'accueil » dans le menu Partager.
